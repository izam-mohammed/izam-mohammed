# Security policy

## Supported versions

There are no releases. Only the latest commit on `main` gets fixes.

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.
Report it privately through GitHub:
[Report a vulnerability](https://github.com/izam-mohammed/izam-mohammed/security/advisories/new)
(the "Security" tab, then "Report a vulnerability").

## What happens next

This is maintained by one person, so there are no guaranteed response
times. The aim is to acknowledge the report, agree on whether it is a
vulnerability, fix it, and credit you in the advisory unless you would
rather not be named.

## Scope

In scope: this GitHub profile README (`README.md`), the SVG files it
shows, and this repository's GitHub Actions workflows. Problems in
GitHub's profile rendering, or in the external sites the README links to,
belong to those services.
